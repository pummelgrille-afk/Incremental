## Findings carried forward

- Each space has a characteristic failure mode: incremental → mid-game dead zone;
  auto-battler → static board is inert to watch; bullet-hell → execution gates
  the audience. The design answers each explicitly.
- The genres differ mainly in **where the player's hands are**. This game's seam:
  auto-battler commitment plus one coarse steering input during the fight.
- Four differentiators recorded, each traced to a specific pillar.
- Four risks logged with mitigations and the phases where they bite.
