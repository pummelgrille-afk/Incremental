# Phase 4: Build an Original Narrative & World

**Stage 0 — Concept & Design Foundation**
Output: `docs/design/narrative.md`

## Checklist

- [x] Original lore, characters and tone written from scratch
- [x] Flavour text per zone (6 zones)
- [x] Flavour text per boss (5 bosses)
- [x] Achievement names fitting the world (12)
- [x] Sanity check: would this stand on its own with no reference game in mind?

## Decisions locked

- **Tone: a maintenance log, not an epic.** Understate the stakes; technical
  vocabulary with plain-language tooltips; no prophecy, destiny, or villain.
- **Three flavour voices:** the Manual (upgrade tooltips), Wright Sabel Ock
  (zone epigraphs), the Undermaster (progression text).
- **Six zones:** Escapement Floor, Hour Ring, Wander Rings, Ring of Fixed Lights,
  Crystalline Drift, Unnumbered Ring.
- **Five bosses**, each a failure mode of the machine given form — never a creature
  or a person.

## Originality check — passed

Fiction and mechanics generate each other rather than sitting side by side: the
rotating grid exists because orrery rings turn; conjunction is astronomical before
it is a synergy trigger; prestige-as-rewinding follows from the objective being a
mainspring. Vocabulary is real horology — public technical language from
clockmaking, not from any game.

Ongoing test for Stages 4–5: does this content derive from **the machine and its
failure modes**? If yes it belongs; if it derives from another game's bestiary it
does not.
